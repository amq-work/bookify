# Bookify SaaS

Bookify is a premium appointment scheduling and business management platform designed for service-based businesses. This repository contains the frontend application, demonstrating product strategy, UX research, CX thinking, UI/UX design, and frontend engineering.

## Project Architect & Product Designer
This SaaS was designed and engineered by **Aayan Qureshi** as a personal portfolio project.

## Features
- **Responsive Dashboard:** A mobile-first, glassmorphism-styled dashboard for managing bookings, customers, services, and business settings.
- **Dynamic Form Builder:** Customizable booking forms that adapt to different business models (e.g., dental, beauty, consulting).
- **Public Booking Pages:** Beautifully designed, customer-facing booking interfaces.
- **State Management:** Fully functional mock database layer showcasing robust client-side state handling.

## Running Locally

**Prerequisites:** Node.js (v18+)

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Deployment
This project is configured for seamless deployment on Vercel and includes integrated Vercel Analytics and Speed Insights.
